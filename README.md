# JavaScript Stopwatch

A simple stopwatch application built using HTML, CSS, and JavaScript.

## Features

- Start the stopwatch
- Stop/Pause the timer
- Reset the timer
- Millisecond precision
- Clean and minimal UI

---

## Built With

- HTML5
- CSS3
- JavaScript

---

## JavaScript Concepts Used

- `Date.now()`
- `setInterval()`
- DOM Manipulation
- Functions
- Conditional Statements
